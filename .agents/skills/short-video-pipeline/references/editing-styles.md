# 竖屏短视频剪辑风格全谱系与蒙太奇刀法规范（Editing Styles & Montage Grammar）

本文件专门定义本工作区短视频的**「导演与剪辑层」**：管**选什么剪辑流派、前 3 秒怎么抓人、台词水词与气口怎么砍、声音与画面怎么错位缝合、景别与虚拟摄像机怎么运动、多轨画面怎么构图、B-roll 怎么蒙太奇切入、全片节奏能量怎么起伏**。

至于每镜内部的动态排印、数据图形动效、光学调色、人像抠像、转场实现与字幕 CSS，统一见姊妹专著 [editing-vfx.md](editing-vfx.md)。

---

## 一、总则：剪辑先于包装，无代号不开工

1. **剪辑决定留存底盘**：任何动态图形与特效都救不活“前 7 秒主持寒暄废话、句内车轱辘口癖、单机位五官跳切抽搐、温吞水匀速念稿、黑屏或张冠李戴 B-roll”。开工写任何 HTML 页面之前，必须先完成**「选定剪辑风格 `S01–S10` → 确定开场钩子 `H1–H6` → 产出二次提纯 `time_slices` 与三级气口方案」**。
2. **全流程强契约绑定**：
   - **步骤 1（选题 `topic/topic.json`）**：必填 `"content_archetype"` 与推荐 `"selected_style"`；
   - **步骤 2（复刻拆片 `ref/out/`）**：将 `rea-video` 拆出的切镜率、运镜和转场映射为本文件的 `S / H / C / L` 代号；
   - **步骤 3 / E2 / E3（分镜 `script/storyboard.json` & `master-plan.json`）**：顶层必填 `editing_style`（`S01–S10`）、`cold_open`（`H1–H6`）、`time_slices`、`silence_drops`，每镜必填 `layout`（`L1–L7`）、`cam`（`C1–C8`）、`cut_note`（`JL1–JL5`），由 `qc_video.py` 静态与动态双重验收。

### 2.1 单片自动选型路由与入口 E 五槽位互斥配对规则

1. **单片入口（A / B / C）选型决策树（步骤 3 必选）**：
   - 无真人出镜口播：突发新闻/行业数据 → `S06`；科技产品/AI 模型发布 → `S05`；观点宣言短片 → `S09`。
   - 有真人出镜口播：含明确步骤方法 → `S10`；纠偏反常识误区 → `S08`；讲品牌/人物故事 → `S07`；算账/周期模型推演 → `S03`；尖锐痛点短平快 → `S02`；创业心路/组织感喟 → `S04`；60s+ 多维商业深访 → `S01`。
2. **矩阵入口（E：强制固定 1 母片 + 4 延伸子片，`00–04` 一一绑定 `G0–G4` 五大账号组 IP 人设）正交互斥规则**：
   - **`00–04` 号组人设与剪辑/封面精准对位表（严禁方向错位或串用 IP 名）**：
     - `00-master` ↔ **`G0` · `跨境AI十亿增长局`**：聚焦跨境 × AI 宏观战略大盘、十亿级规模增长格局与组织进化全景 → **`S01` 商业旗舰纪实流**（封面 `C1` 头顶居中标题画报）；
     - `01-v1` ↔ **`G1` · `时奕聊AI经营`**：聚焦“聊”——犀利对谈破题、一线经营体感快问快切与反差冲击 → **`S02` 网感痛点暴击快剪流**（封面 `C2` 头顶居中战报画报）；

     - `03-v3` ↔ **`G3` · `老郑AI经营实战`**：聚焦老郑一线操盘复盘、打破行业旧共识与实战避坑判断 → **`S08` 双视角交锋/认知证伪流**（原片含完整案例时间线可弹性换 `S07` 案例深扒流；封面 `C5` 头顶居中误区划除画报）；

   - **灰度盲测硬红线**：所选 **5** 个槽位将成片抽去色彩转为黑白灰后，必须在 **① 画布底色明度（至少 1 片暖纸亮底 vs 深墨/炭黑/双域对撞底）、② 人物出镜与画幅构图（侧分栏纪实 vs 全屏阶梯跳推 vs 全幅暖纸画板无大窗 vs 冷暖双域斜切/上下交锋屏 vs `2.39:1` 宽银幕浅景深）、③ 字幕排印体制与纵向 `top` 五级等距阶梯（`1320 / 1366 / 1412 / 1458 / 1504px`，相邻间距 `≥40px`、总极差 `≥160px`）、④ 剪辑节奏 ASL** 四个维度完全正交互斥！

| `H6` | **时空坐标纪实切片** | `0.00–2.40s` 调色实景空镜叠印大字重纪年/地点坐标（如 `2021 · 深圳坂田`），L-Cut 引入人物独白 | `S04` 电影独白、`S06` 新闻快讯、`S07` 案件故事 |

### 类别 2：EDL 逐字稿二次提纯与三级气口刀法（`D1–D5`）

1. **`D1` 破除「已粗剪 = 免精剪」铁律**：输入来自 `素材投递区/已粗剪/` 时，`master-assets/clips/` 保留物理无损底片维护统一时间戳，但**下游母片与全部子片严禁 `#t=0,end` 整段原样直铺**，必须在 `storyboard.json` 编写 `time_slices` 做二次精剪。
2. **`D2` 五类必删废句清单（开工前逐句对照 ASR 划除）**：
   - 画外冗长串场寒暄（*“然后最近反正你也接了一些老板……”*）；
   - 现场失忆/犹豫求证（*“那个时候应该是几几年，大概21年吧……”*）；
   - 空洞过桥口头禅（*“就是我们讲普遍性的”*、*“那另外我们发现一件事情就是”*）；
   - 口误结巴自我重说（保留说得最干净笃定的后半遍，删掉前半遍结巴）；
   - 跨切片无前文悬空代词（*“像我刚刚讲的”*、*“反而是”*、*“那这个”*）。
3. **`D3` 分风格常规句间气口压缩区间**：
   - 快剪类（`S02 / S06 / S09`）：句间静音收紧至 **`0.08–0.18s`**；
   - 纪实/图解/评测类（`S01 / S03 / S05 / S07 / S08 / S10`）：保留自然语流 **`0.18–0.32s`**；
   - 电影独白类（`S04`）：保留思考张力 **`0.30–0.55s`**。
4. **`D4` 论点换挡声学换气窗**：大段落或章节切换处，预留 **`0.40–0.65s`** 无台词呼吸窗，供 `build-bgm-bed` 侧链自动把配乐推起 `+3.5 dB` 承接视觉转场。
5. **`D5` 金句屏息真空窗（Silence Drop）**：每片选定 `1–2` 处最扎心的核心结论句，开口前留 **`0.35–0.45s`** 屏息，同时在金句前半句（`1.2–1.8s`）将 BGM 彻底抽空至静音（画面与人声正常推进，绝不干停冷场！），尾字落定瞬间重推配乐。

### 类别 3：声画错位缝合与防跳切抽搐 5 法（`JL1–JL5`）

- **`JL1` 听觉先导切（J-Cut）**：从 B-roll/图形切回真人前 `0.20–0.35s`，先让下一句真人声音响起，再切画面。
- **`JL2` 视觉接力切（L-Cut）**：真人说到半句具象名词时，画面提前 `0.30–0.50s` 切向实证 B-roll 或数据动效，人声继续在画面下说完。
- **`JL3` 非连续源切口强制掩护铁律（根治五官瞬移抽搐）**：凡 `film.html` 中相邻两段同源口播 `<video>` 满足 **`|prev.t_out - curr.t_in| > 0.08s`**（即中间删了水词或做了冷开跳转），**严禁两个同机位人像镜头直接相邻硬切**！必须在切口上方覆盖 **`≥ 1.5s`** 的全屏 B-roll / 动态排印舞台，或插入显式过渡桥接（如 `S02` 的 `TR9` 故障切、`S04` 的 `TR3` 沉黑），由 `qc_video.py` 硬阻断违规裸拼。
- **`JL4` 顺手势/抬头动作切（Match-on-Action）**：景别跳推优先选在主讲人抬手强调或转头定睛的动作起始帧。
- **`JL5` 小节重拍锁切（Beat-Locked Cut）**：快节奏风格中，全屏大字砸入与 B-roll 硬切点对齐配乐鼓点瞬态。

### 类别 4：四级景别阶梯与虚拟摄像机运镜 8 法（`C1–C8`）

全部利用 `1440p` 快解母片冗余像素与 OpenFilm 原生 CSS 动画属性（`scale`、`translate`、`rotate`、`--fx-ax/ay`、`--fx-rx/ry/z`、`--fx-blur`）实现，**严禁在句中半腰硬剁 `<video>` 凑跳切，严禁相邻连续 `<video>` 重复挂载同一起点缩放造成画面倒退抽搐，严禁对自身已有推拉摇移或轻微手持运动的 B-roll `<video>` 再叠加 CSS `scale` 缩放动画（双重运镜打架必放大背景抖动，由 `qc_video.py` 硬拦截）**：

```css

@keyframes kfRackIn { from { --fx-blur: 12px; scale: 1.04; } to { --fx-blur: 0px; scale: 1.00; } }
```

### 类别 6：B-roll 蒙太奇选用、稳像防抖与六维签收 8 律（`B1–B8`）
- `B1` **动静与竖屏源优先级**：原生 `9:16` 竖屏三脚架/云台稳像 `.mp4`（单支 `2–4` 段，优先走 Pixabay `video-search --orientation portrait` 或 `fetch_asset.py stock --kind video`）> `L3/L6` 视窗内的 `16:9` 稳像 `.mp4` > 真实新闻/官网 3D 聚光截图（`PF6`）> 叠前景矢量动效的高清原图（`PF7`）。
- `B2` **单一连续镜头铁律**：截取区间 `[t_in, t_out]` 内严禁包含原素材自身的切镜跳变（`scdet score < 16`）。
- `B3` **掐头去尾防黑屏死帧**：入片区间内严禁存在未显影黑屏或转场黑尾（全采样帧亮度均值 `YAVG ≥ 18`）。
- `B4` **零内嵌脏字/水印**：严禁含原视频硬字幕、地名标（如 `YANTIAN, CHINA`）、商业广告牌（`#HelloHudsonYards`）或媒体台标。
- `B5` **地域与人性温度对齐**：讲深圳/本土产业严禁拿欧美地标冒充；讲团队年龄/管理心态严禁用阴森无人空走廊充数。
- `B6` **防截肢裁切与跨片感知哈希唯一性**：`<img>` 禁止宽高比畸变 `> 2.2×` 的 `object-fit: cover` 盲裁；单支视频内及入口 E 跨 5 片之间，全部补充 B-roll 必须通过 `64-bit dHash` 感知哈希去重（汉明距离 `> 10`，严禁把同一仓库视频改名多开）。
- `B7` **稳像零往复抖动、运镜解耦与横竖构图铁律（根治背景来回晃动）**：
  1. **源头禁选高危震荡片**：严禁选用人行天桥/夹层共振快放延时（`timelapse/hyperlapse`）、手持边走边拍步伐抖动、船上颠簸跟拍或带机内防抖果冻畸变的业余摇晃片段；舞台折算高频急动度 **`hf_jerk > 2.40px` 或往复反向率 `> 2.50/s`** 属 `Tier C` 严重抖动，由 `qc_video.py audit-render` 一票否决硬阻断；轻微手持微晃（`1.25 < hf_jerk ≤ 2.40px`）入库前须执行 `qc_video.py stabilize-broll` 二次光学稳像（稳像后仍处 `Tier C` 则直接废弃换片）；
  2. **原生运镜与人工缩放解耦**：仅**锁死三脚架绝对静止**视频或静态图片可叠加 `C1/C2`（`scale: 1.00→1.07`）缓慢推拉；凡素材自身已含云台推进、航拍平移或任何画面位移（`mean_speed > 0.45px/f` 或 `hf_jerk > 0.40px`），**严禁再挂 CSS `scale` 缩放动画**，防止径向放大与横向位移打架引发背景拉扯眩晕；
  3. **`16:9` 横屏慎做 `1.78×` 满屏硬拉**：`1920×1080` 横屏素材若用 `object-fit: cover` 硬铺满 `1080×1920` 全屏，会将水平微晃直接放大 `1.78×`；非锁死三脚架的 `16:9` 实拍优先放入 **`L3` 上半屏实景窗（`1080×680px`）或 `L6` 宽银幕遮幅窗（`1080×452px`）**，从几何上消除横向放大失真。
- `B8` **API 候选多选一与六维制作要求实看签收铁律（严禁盲拿首条充数）**：通过 Pixabay / OpenFilm / 公开库 API 搜到的素材，**严禁只凭英文标签拿第 1 条盲塞入片，严禁塞“假笑握手/敲键盘/公路卡车”等与台词脱节的万能水片**！必须先在 `materials/` 下载 `2–4` 个候选并查看 `candidate-sheet-*.jpg` 4 帧拼图，逐一核验**台词语义咬合、地域文化零穿帮、竖屏主体不被字幕遮挡、影调色温契合 `S01–S10` 风格及稳像清晰度**，剔除不符项后用 `fetch_asset.py register --shot <镜号> --fit-reason "<≥12字实看核验说明>"` 写入 `credits.json`（未签收素材由 `qc_video.py` 硬阻断）。

### 类别 7 & 8：宏观能量曲线与片尾收束 4 范式（`O1–O4`）
- **防同构疲劳铁律**：任意成片严禁连续 `> 18.0s` 停留在同一种构图拓扑而不发生景别跳推或舞台切换；`>60s` 长片每 `25–30s` 必须安排一次视觉+配乐换挡。
- **片尾收束 4 范式**：`O1 核心定论金句+品牌极简微标收束`（通用）、`O2 一屏三点收藏复盘卡`（`S10` 专用）、`O3 回切主讲人笃定眼神+配乐 Swell 上推余韵`（`S01/S07`）、`O4 慢速真溶黑电影落幕`（`S04` 专用，终帧纯黑 `opacity: 1.0`）——均须满足末句语义完整（加 `40ms` 微淡出）、核心落版停留可读 `≥ 1.5s`、落音后留 `0.6–1.2s` 尾韵且片尾 `0.35s` 音频均值 `≤ -25 dB`。
