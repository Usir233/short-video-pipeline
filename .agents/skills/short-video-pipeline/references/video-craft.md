# 短视频视听导演与反违和规范（画面结构、字幕、动效、音效）

本文件用于解决自动化短视频流水线最常见的顽疾：**“像前端网页/PPT 拼出来的流水线成片，特效、字幕、画面结构、音效堆在一起非常违和”**。

所有进入步骤 3（分镜）、步骤 4（素材）、步骤 5（剪辑与渲染）及入口 E（母片 + 3 子片）的制作任务，**必须在动笔写 `storyboard.json` 与 `film.html` 前先整篇通读本文件**，并与 `node_modules/openfilm/manual/film/SKILL.md`、`node_modules/openfilm/SPEC.md` 配合执行。

> **参考标杆语境**：对标一线商业/AI/知识口播创作者的真实视听语法——如影视飓风、小Lin说、何同学、Ali Abdaal、Dan Koe、Iman Gadzhi 及国内高完播商业 IP。它们共同的底层秘诀不是“每秒堆满特效”，而是：**人声与眼神为主体、构图极简留白、动静有呼吸、字幕长在画面里、音效隐形服务情绪**。

## 一、反流水线 5 条铁律（红线禁区）

任何口播/知识/商业解析视频，触犯以下任意一条即判视觉/听觉违和，必须返工：

1. **禁止把真人长期关进“网课小窗 / 监控画中画”**：
   - 有真人出镜口播时，**真人全屏出镜占比默认须 ≥ 55%–75%**（纯无出镜资讯片除外）。
   - **禁止将「顶部横屏口播小窗 + 下半卡片区」当默认模具反复套用**，也禁止在每段 B-roll 右上角都机械挂一个带发光边框的“会议/监控小窗”。
2. **彻底戒掉“前端 SaaS Dashboard / 网页后台”审美癖**：
   - 严禁把视频画面做成企业中台/网页截图：禁止满屏 `1px solid` 细线圆角框、多列 3–6 格参数卡片墙、顶部常驻“网页导航栏/课程章节进度条”、以及装科技感但普通观众根本不看的无意义英文装饰眉标（如 `STEP 01 // MEMORY CAPTURE`、`USER PROFILE`、`LIVE SYNCING`、`PRECISION MATCH`、`TRUST GUARD` 等）。
3. **一帧只留一个视觉焦点（One Focus Per Beat）**：
   - 除常规字幕外，任意单帧屏幕内**最多 1 组核心视觉要素**；屏幕辅助/图形文字总计 **≤ 20–25 字**；核心大字 **≥ 56px**，次级说明 **≥ 32px**（坚决杜绝手机上看不清的 14–22px 蚂蚁字）。
4. **必须保留“纯人像呼吸留白段”**：
   - 全片至少 **25%–35%** 的时长保持**完全干净的全屏人像 + 字幕**（零贴纸、零卡片、零顶栏、零边框），给眼睛和大脑喘气空间。**80% 干净克制 + 20% 精准爆发，才叫高级感。**
5. **禁止机械打卡式音效与死直线 BGM**：
   - 严禁“每切一镜就咻一声、每弹一张卡就啵一声”，严禁把刺耳电子音/高音铃铛开大盖过人声，严禁 BGM 从头到尾一条死直线零情绪停顿。

## 二、画面整体结构：4 种高级镜头语法（替代单模具）

做分镜（`storyboard.json`）时，每条口播视频通过以下 **4 种电影/短视频原生镜头语法** 有机交替，而不是把人塞进小框里读 PPT：

### 镜头型 A：全屏口播 + 4K 无损伪多机位推拉（主力镜头，占 50%–65%）
- **做法**：直接用高分辨率竖版口播画面满屏出镜，在 `film.html` 中按语义节拍切分 **3 档景别**，靠跳切制造呼吸感与专注度：
  - **中景（基础叙述）**：`scale: 1.00`（缓慢呼吸推进至 `1.03`，极克制不晕眩）；
  - **近景（重点转折/举例子）**：干脆跳切至 `scale: 1.10–1.14`；
  - **特写（核心金句/灵魂反问/情绪爆点）**：干脆跳切至 `scale: 1.18–1.24`，眼神直击观众。
- **干净留白**：其中至少一半全屏口播镜 **不叠加任何图形或角标**，仅保留画面底部的轻盈字幕与极柔和底部透明渐变暗角（保证字幕清晰即可）。
- **去顶栏**：**默认不在顶部焊死常驻品牌条或章节进度条**；品牌露出只在结尾最后 1.5–2.5 秒做轻量落版，或使用极低存在感的局部角标。

### 镜头型 B：全屏口播 + 局部轻量空间浮层（占 15%–25%）
- **做法**：人像继续保持满屏，只在说话人讲到具体案例、产品、关键概念时，于**胸前偏下或肩侧自然留白处**弹出 **1 个极简要素**（停留 `1.8–3.5s` 后干净收起）：
  - 4–8 字手绘感/无框大字关键词（或手绘高亮下划线/圈注）；
  - 1 张轻盈悬浮的真实产品图 / 极简聊天泡泡 / 单条金句条（无重型后台框架、不盖脸、不盖嘴、不占超过 1/3 屏）。
- **进阶空间景深技法（OpenFilm 原生支持）**：
  - 在片头 3 秒钩子或全片最高光金句，可使用 OpenFilm 原生人像抠像属性 **`--of-cutout: 1`**（见 `node_modules/openfilm/SPEC.md` §1，搭配 `--of-cutout-mode: 1`、`--of-cutout-edge: 0.25`、`--of-cutout-despill: 0.35`），将超大号标题文字或轻柔光晕置于 **人物背后、背景之前**（人前字后景深层次），质感远超平面贴纸。使用前须用 `openfilm look` 检查抠像边缘，边缘不干净时立即退回普通全屏 + 无框前景大字。

### 镜头型 C：全屏动态 B-roll 切走（占 15%–25%，干脆全屏！）
- **核心铁律**：切到 B-roll 画面时，**默认 100% 全屏切走（单镜 `2.0–4.5s`），绝不在右上角硬贴“画中画监控小窗”**！人声保持连续（J-cut / L-cut），观众自然听声看画。
- **动态视频优先于静态照片**：
  - 优先获取真实动态竖屏视频（OpenFilm 内置 Pexels/Pixabay `--orientation portrait`、官方发布会/Demo ≤6s 切片、公开免版权视频）；
  - 静态图片仅在确实找不到匹配动态视频时兜底，**单张静态图停留严格 ≤ 3.5 秒**（严禁拿一张静止图缓慢缩放 10–17 秒当垫底背景！）。
- **让画面自己说话**：B-roll 保持自然光影与轻微电影调色，**禁止给实拍画面糊一层 80% 死黑遮罩后再在上面堆 3 张网页卡片**；如需说明，最多在留白处放 1 句 ≤10 字的极简短标与角落小号来源标注。

### 镜头型 D：全屏极简概念动画 / 白板手绘隐喻（占 10%–20%，少而精）
- **使用时机**：只有当口播讲到“抽象结构/因果链路/二元对比/流程演进”且纯实拍讲不清时才切入，每次停留 `3.0–6.0s`。
- **极简画布铁律（对标 Apple Keynote / Dan Koe / 小Lin说）**：
  - 一屏只演 **1 个直观视觉动作**（例：旧逻辑向新逻辑升维切换；手绘白板红笔一划删掉误区、勾出要点；两条路径一左一右分叉）；
  - 全屏文字总计 **≤ 20 字**，核心词字号 **64–96px**，节点数 **≤ 3 个**，留白面积 **≥ 45%**；
  - 若极少数场景确需“人 + 极简图示”同框，全片最多出现 **1 次**，且采用**自然上下呼吸留白或抠像融合**，绝不套用“顶部 280px 扁框人头 + 下半 6 格表格”的模板。

## 三、字幕与花字融合体系（告别“厚黑膏药补丁”）

字幕是观众停留最久的视觉元素，必须像原生电影/头部博主一样**“长在画面里”**，而非像老旧网页播放器硬贴上去：

1. **彻底淘汰厚重纯黑方块底**：
   - **暗调/真人全屏画面**：禁止给 `::cue` 设置厚重不透明纯黑背景块（`rgba(0,0,0,0.85)` 会在不等长两行字后露出参差不齐的黑补丁）。统一改用 **透明底 + 暖白/纯白粗体无衬线（`Noto Sans SC` `700/900`，`44–50px`）+ 细腻深色描边与多层柔影**（例如 `background: transparent; text-shadow: 0 2px 4px rgba(0,0,0,0.85), 0 6px 18px rgba(0,0,0,0.55); -webkit-text-stroke: 1.5px rgba(0,0,0,0.45);`），配合人像底部一层极柔和的透明渐变暗角（`rgba(0,0,0,0) → rgba(0,0,0,0.45)`），既极其清晰又毫无割裂感。
   - **浅色/暖白白板画面**：字幕直接采用干净深墨字（`#14212B`，透明底 + 极轻暖白外晕）或与画面同色系的极轻半透明衬条，绝不把一块沉重深蓝大胶囊突兀地扔在白纸底部。
2. **短句节拍断句（单行至上）**：
   - **每条 cue 默认单行、严格控制在 6–12 个汉字**（最长不超过 14 字，宁可快节奏切分，绝不把 20+ 字的长句堆成笨重双行块）。
   - 按口播实际气口和语意单元切分时间戳；可适度去掉字幕显示中的无意义口癖（如「那个」「然后就是说」），保持视觉干爽又不歪曲原话。
3. **原生关键词高亮与微动效（充分利用 OpenFilm WebVTT 能力）**：
   - 依据 `node_modules/openfilm/SPEC.md` §1 Captions，OpenFilm 原生支持 WebVTT `<c.hi>` 标签、`:past`/`:future` 词级高亮及 `@keyframes` 动画。
   - 每 1–2 句挑出 **1 个核心信息词** 用 `<c.hi>关键词</c>` 标成该片唯一的主题强调色（如暖琥珀 `#F6C15C`、清透薄荷 `#5EEAD4`、朱砂红 `#E05A47`），可选配合极克制 `0.12s` 轻弹入场，切忌整句五颜六色或剧烈乱蹦。
4. **位置锁定与文字零打架**：
   - 字幕基线锁定在下中黄金视觉区（`y ≈ 1340–1450px`，即 `line: 71%–75%`，稳避平台底部 360px UI 遮挡），全片基线**保持稳定不上下跳动**；
   - **防双层重复铁律**：当画面中央已经打出全屏大字金句（镜头型 D）时，对应那 1–2 秒隐藏或弱化底部同内容常规字幕，绝不让“屏幕正中大字”和“底部字幕”把同一句话写两遍！

## 四、动效质感、色彩统一与视听卡点

1. **物理阻尼缓动（禁用机械 `linear` 弹入）**：
   - 所有浮层、关键词、卡片、线条动画统一使用快进慢出缓动（`cubic-bezier(0.22, 1, 0.36, 1)` 或三次缓出 `1 - Math.pow(1 - p, 3)`），入场时长控制在 **`0.22–0.38s`**，位移克制在 **`16–28px`**（不要从屏幕外飞奔 500px 砸进来）。
   - 仅慢速镜头推拉（Ken Burns / 微推）使用 `linear`。
2. **语义卡点，而非整数秒瞎切**：
   - 景别跳切、全屏 B-roll 切入、浮层弹出，必须严格对齐 `transcript` 中**对应关键词出口前 0.05–0.10s 或句首气口**；禁止强行按 `4.0s`、`8.0s`、`12.0s` 等机械整数秒切镜。
3. **克制转场（硬切为王）**：
   - **85% 以上镜头切换采用干净利落的硬切（Hard Cut）**，靠声音连续性（J-cut / L-cut）与景别变化自然衔接；
   - 仅在大的情绪/章节转折处（全片 ≤ 2–3 次）使用 `0.2–0.35s` 双轨平滑叠化（`overrides='[{"fade":[0.25,0.25]}]'`），禁止花哨旋转、百叶窗、炫光闪白转场。
4. **色彩与光影世界观统一**：
   - 全片锁定 **≤ 2 个基础中性色（深底/浅底 + 文字主色）+ 1 个主题点缀色**；
   - 原片人像若偏灰或与图形层割裂，优先通过 OpenFilm CSS `filter`（微调 `contrast` / `saturate` / 色温）或 `--of-lut` 做统一轻度调色，确保真人皮肤质感自然红润、图形层融入同一光影氛围。

## 五、声音导演规范：克制音效 + BGM 情绪呼吸

声音违和往往比画面违和更让人瞬间划走。声音设计严格执行以下三层标准：

### 1. 人声（第一绝对主角）
- 最终成片维持 `-14 LUFS`、真峰值 `< -1.0 dBTP`；原片口播保持清晰贴耳、自然语速与呼吸，不被任何音乐或音效盖住 1–4 kHz 人声核心频段。

### 2. BGM 情绪曲线与「静音真空（Silence Drop）」
- **托底音量**：人声讲话时，BGM 感知响度压低在人声下方 **-22 dB 至 -26 dB**（OpenFilm `volume` 通常落在 `0.07–0.13`，视音源本身响度按 `openfilm look` 波形实测校准；绝不盖过人声）。
- **打破死直线（必做呼吸设计）**：
  - **≤ 60s 短片**：至少设计 **1 次**「静音真空」或段落起落；
  - **> 90s 长片**：至少设计 **2–3 次** 情绪呼吸——在抛出颠覆性反问、反转金句或核心结论前 **`0.3–0.6s`** 将 BGM 柔淡抽空至静音，让纯人声在安静声场里贴耳击中观众，待金句落定后再在下一段自然渐入或切入更轻快的副歌段。

### 3. 音效（SFX）极度克制铁律
- **全片总数硬上限**：
  - **≤ 35s 短片**：SFX 总数 **≤ 4 个**；
  - **35–75s 中短片**：SFX 总数 **≤ 6–7 个**；
  - **> 90s 长片**：SFX 总数 **≤ 10–12 个**。
- **落点原则（宁缺毋滥）**：
  - 普通景别跳切、常规字幕刷新、普通 B-roll 切入 **一律不配音效**；
  - SFX **只落在**：① 片头 0–2s 核心钩子建立；② 真正的大转折/认知反转；③ 全屏核心概念动画的关键一笔（如手绘划掉误区、结构图主节点亮起）；④ 结尾金句落定。
- **选型与音量红线**：
  - **优先选型**：极轻柔空气扫风（soft air whoosh）、沉稳低频微震（subtle low boom / riser）、自然材质轻触（paper brush / soft wood tick / gentle pencil）；
  - **严禁滥用**：尖锐刺耳的电子故障音（glitch）、卡通夸张弹簧/啵啵声、高音量刺耳玻璃铃铛（chime）；
  - **音量硬上限**：SFX 感知响度统一压在人声下方 **-18 dB 至 -26 dB**，轻托画面动势而非喧宾夺主（**绝不允许出现 `volume="0.7–0.9"` 的刺耳音效猛砸人声**，如音源本身极轻需调增益，也必须以 `openfilm look` 实测分贝远低于人声为准）。

## 六、已定版的 4 槽位固定视觉风格与配色系统（母片 + 3 延伸子片默认沿用）

以下 **4 套视觉风格与标准配色** 已经实片审验通过，正式沉淀为本工作区后续 **「1 母片 + 3 子片」矩阵（入口 E）及单条视频选型的默认固定视觉系统**（除非用户显式指定新号组或新色系）。

> **核心融合原则（务必同时守住两条线）**：
> 1. **视觉风格与标准配色 100% 沿用下表 4 套定版色板**（保持全矩阵跨期品牌识别度、明暗区隔与封面/成片高度一致）；
> 2. **画面结构、字幕、动效与音效严格执行本文件第一至第五节的导演反违和规范**（全屏人像主舞台 ≥55%、纯人像留白 ≥25%、去网课小窗与 SaaS 卡片墙、透明描边短句高亮字幕、BGM 静音呼吸与克制低频 SFX）——即**“保留已签收的 4 套高级视觉风格配色，全面升级为电影/头部口播的镜头与声画语言”**。

## 七、出片前 10 项导演级审美反违和门禁（硬性自检）

每次完成渲染前（`openfilm look` 预检）及渲染后（`openfilm look --full` 复核），必须对照以下 10 项逐一自查并写入 `output/check/check.json` 的 `aesthetic_checks` 字段；**任意一项不达标即判违和，必须重构修改，禁止带病交付**：

| # | 检查项 | 通过标准（硬指标） |
|---|---|---|
| 1 | **全屏人像主舞台** | 真人口播片全屏出镜占比 ≥ 55%；未把「顶部小窗 + 下半卡片」当默认模具反复套用；B-roll 切走未机械贴右上角监控小窗。 |
| 2 | **去“网页后台/PPT”感** | 无常驻顶部导航栏/课程进度条、无无意义英文装饰眉标（`STEP 01 // ...`）、无多格细框 SaaS 卡片墙。 |
| 3 | **单帧单焦点与字号** | 任意单帧除字幕外最多 1 组焦点要素、图形辅助字 ≤ 25 字、核心字 ≥ 56px、次级字 ≥ 32px，手机竖屏一眼可读。 |
| 4 | **纯人像呼吸留白** | 全片有 ≥ 25% 的纯人像干净画面（零贴纸、零卡片、零顶栏），视觉有张有弛。 |
| 5 | **B-roll 生命力** | 优先真实动态视频；单张静态兜底图停留 ≤ 3.5 秒，未出现静态图硬撑 10 秒以上，未给实拍图强糊厚黑遮罩再堆网页卡片。 |
| 6 | **字幕去黑膏药与短句** | 透明底细腻描边/柔影字幕（无参差黑块补丁）；单行 6–12 字按气口断句；重点词克制高亮；基线稳定在 `y ≈ 1340–1450px` 避开底部 UI。 |
| 7 | **文字零重复打架** | 画面中央大字金句/图解文字与底部字幕不重复复读、不遮脸、不重叠互抢。 |
| 8 | **物理缓动与语义卡点** | 元素入场用快进慢出缓动（`0.22–0.38s`），禁用生硬 `linear` 弹窗；切镜与浮层卡在语流重音/气口而非整数秒硬切。 |
| 9 | **音效极度克制防抢声** | SFX 总数在硬上限内（30s ≤ 4、60s ≤ 7、140s ≤ 12）；无每切必“咻”机械打卡；无刺耳电子/高音铃盖人声，音量低于人声 18–26 dB。 |
| 10 | **BGM 呼吸与整体体感** | 口播时 BGM 稳压在人声下方（-22~-26 dB），全片至少 1 次（长片 2–3 次）情绪静音真空或段落起伏；整体观感像真人头部剪辑团队作品而非流水线模板。 |

## 九、OpenFilm 可直接复用的高级视听配方与自动化脚本

本节将前文规范直接落为**可复制的 OpenFilm 工程代码**与**零依赖校验脚本**，彻底消除凭感觉“盲写 CSS/VTT”带来的风格漂移。

### 1. 一键生成高质感透明短句高亮字幕（`scripts/format_captions.py`）

制作任何口播视频（含入口 E 子片切片）时，**先用本脚本从原始 `.srt` / `transcript.json` 生成短句 WebVTT**，严禁把 20 字双行原字幕配不透明黑块直接塞进 `film.html`：

```bash
. .agents/skills/short-video-pipeline/scripts/env.sh

python3 "$SVP_ROOT/.agents/skills/short-video-pipeline/scripts/format_captions.py" \
  --in runs/<目录>/master-assets/clips/clip-01-transcript.json \
  --out runs/<目录>/film/assets/captions.vtt \
  --start 0 --end 50.57 \
  --max-chars 12 \
  --theme master \
  --highlight "<核心词1>,<核心词2>,<核心词3>" \
  --mute-ranges "27.5-30.0" \
  --trim-fillers
```

- `--theme` 支持 4 槽位定版别名与通用预设：`master`（同 `dark`，墨黑铜青暖白+铜青高亮）、`v1`（同 `punch`，深蓝黑纯白+电光青微弹）、`v2`（同 `light`，暖白白板深墨+翡翠青高亮）、`v3`（同 `cinema`，黑曜石暖象牙金+极光薄荷高亮）；
- `--mute-ranges` 填入全屏大字金句卡片的起止秒，自动在该时段隐藏常规字幕，彻底杜绝上下文字复读打架。

### 2. 渲染前强制跑反违和自动质检（`scripts/check_craft.py`）

写完 `film.html`、`captions.vtt` 和各镜 HTML 后、正式 `openfilm render` 之前，**必须执行本脚本**，任一硬性报错未归零不得渲染交付：

```bash
python3 "$SVP_ROOT/.agents/skills/short-video-pipeline/scripts/check_craft.py" \
  --film runs/<目录>/film \
  --mode talking_head \
  --json-out runs/<目录>/output/check/craft-lint.json
```

脚本自动解析 `film.html`、`captions.vtt` 与全部 `<iframe>` 场景页，定量核查全屏人像占比、小窗/PiP 滥用、纯人像留白占比、静态图超时（`>3.5s`）、英文代码眉标/常驻顶栏/多格细框卡片墙、黑膏药与长句字幕、SFX 数量/高音量/每切必咻、BGM 静音呼吸，并输出 `aesthetic_checks` 供直接汇总写入 `output/check/check.json`。

### 6. 极简概念动画页缓动模板（禁用 `linear` 弹窗）

```js
// 物理阻尼快进慢出（0.28s 入场，微位移 22px，干净利落不晃眼）
const clamp = (v, a = 0, b = 1) => Math.max(a, Math.min(b, v));
const easeOutCubic = (x) => 1 - Math.pow(1 - clamp(x), 3);

function enter(t, start, dur = 0.28) {
  const p = easeOutCubic((t - start) / dur);
  return { opacity: p, ty: (1 - p) * 22 };
}
```
