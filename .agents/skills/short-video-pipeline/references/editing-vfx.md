# 剪辑方式与 OpenFilm 特效工艺规范（Editing & VFX Craft）

本文件沉淀本工作区从「静态网页卡片 PPT 感」升维至「商业成片级剪辑与动态视觉（Motion Graphics & VFX）」的硬性工艺规范与可复用 OpenFilm 原语库，适用于全入口原创/复刻视频及入口 E 全部 4 个槽位（`00-master` / `01-v1` / `02-v2` / `03-v3`）。

所有特效原语均严格基于本工作区 OpenFilm 0.1 协议（`node_modules/openfilm/SPEC.md`）原生能力与确定性 `window.film.frame(t)`，不依赖额外全局包。

## 一、分风格剪辑节奏与反死镜量化红线

**核心原则：禁止用单一「大头全屏 ↔ 顶部静止 PiP + 底部圆角网页卡」二元模板套所有风格。** 源片为 4K（`3840×2160`）时拥有 `≥2×` 无损裁切与跳切空间，必须真正用出景别语言。

| 槽位 / 风格 | 目标有效 ASL（平均镜长） | 固定 PiP 连续滞留上限 | 单镜零视觉变化空窗上限 | 全屏 B-roll / 全屏图形占比 | 4K 景别与运镜硬要求 |
|---|---:|---:|---:|---:|---|
| **`00-master`（商业旗舰长口播 >60s）** | **≤ 6.5s** | ≤ 25s（≤2 镜） | **≤ 3.5s** | ≥ 15% | 单镜口播 `>6s` 须配锁眼缓推（`--fx-ax/--fx-ay`）或 4K 景别跳切；后段禁止 20s+ 无变化长死镜 |
| **`01-v1`（高节奏实证网感风）** | **≤ 3.5s** | ≤ 8s（禁止连续 2 镜锁死同位 PiP） | **≤ 2.2s** | ≥ 20% | 口播 `>4.5s` 必须按意群做 `≥12%` 阶梯跳切（如 `1.00 → 1.15 → 1.28`）；严禁 `<8%` 匀速微推假装快节奏 |
| **`02-v2`（暖白结构化清单风）** | **≤ 6.5s**（镜内步进 `1.2–2.2s`） | 同高度锁定（如 `384px`），切章须有视觉纸面滑动 | **≤ 3.0s** | ≥ 15%（含全幅图解或终局展开） | 严禁 PiP 高度无动机漂移（如 `400→342→376`）；每条清单项须逐条渐进揭示并配完整组音效 |
| **`03-v3`（黑曜石电影金句沉浸风）** | **5.0–7.5s**（允许克制留白） | ≤ 14s（须穿插全宽空镜呼吸切出） | **≤ 4.0s**（除刻意纯黑屏息外） | ≥ 20%（`2.39:1` 宽幅电影空镜/双轨浅景深） | 禁止把连续口播切碎并复用同套 `scale` 动画造成缩放回弹；高潮段用单条连续 `<video>` 单调推近 |

### 视觉信息密度与“口播→动效”先导规划红线（彻底消灭静态 PPT 感）

开工写 `film.html` 前，**必须在 `script/storyboard.json` 中逐镜写清「口播句 → 配套 SVG/Canvas 动画或动态素材 → 触发时间点 → 转场特效」**，再按以下硬量化指标落盘代码（禁止先套圆角文字卡片模板再往里填字）：

1. **纯文字圆角卡片占比 `≤ 25%`**：单支视频的内容场景中，没有任何 SVG 图形动画、Canvas 动效、动态贴纸或实拍/图文素材的“纯文字框镜头”必须控制在 **`≤ 25%`**。
2. **语义级 SVG / Canvas 定制动画占比 `≥ 45%`（强制绑定真实台词局部秒数 `local_t`）**：凡口播讲到**流程、冲突、对比、对话演示、因果链路、人数规模、等级阶梯、数据汇聚、时间节奏**时，禁止只弹静态文字盒，必须用 SVG（`stroke-dashoffset` 描边 + `getPointAtLength` 沿路径流动光点 + 矢量节点/拓扑/天平/柱图/时间轴）或 Canvas 做出**与 `subtitles.html` 逐句真实时间戳精确卡点（`local_t = cue_start - clip_at`，误差 `≤ 100ms`）的渐进式动态演绎**——**严禁在 HTML/SVG 第 0 帧把全镜多行文字一次性静态摊牌，严禁拍脑袋套用 `0.2 + i * 0.8` 等差秒数导致动画前半程播完、后半程死镜，严禁生造口播未提的虚构长词组造成观众眼耳打架**（详见 §二.9）。
3. **静态 B-roll 全面“动效合成化”**：严禁对静态 AI 生图或照片 `.jpg` 只做 5% 死板缓慢缩放（Ken Burns 静图硬拉）；每张静态 B-roll 场景必须叠加**与口播内容绑定的 SVG / Canvas 矢量前景动效层**（沿路径流动的数据脉冲、扫描准星、节点连线点亮、区域聚焦高光或双层视差），让每一帧都有持续的动态信息量。

### 强制剪辑禁令
1. **零句中硬切版式**：切镜点必须落在字幕停顿缝隙并与 `subtitles.html` 边界严格对齐，禁止在完整分句的定语与宾语中间突然把全屏口播缩进 PiP。
2. **跨轨防浮点叠影（防双人头 1 帧穿帮）**：当上轨 `<section id="speaker-pip">` 切换到下轨 `<section id="main-stage">` 全屏同主体 `<video>` 时，因 IEEE-754 浮点累加误差（如 `33.2 + (130.65 - 118.05) = 45.80000000000001`），上轨 `#t=in,out` 结束时间**必须比下轨起点提前至少 `1 帧（≥ 0.034s）`**，或采用显式跨轨形变转场无缝交接。
3. **连续同机位防缩放回弹**：同一连续源片段跨场景更换前景贴片时，**禁止**将底层 `<video>` 拆成两段并挂同一套 `@keyframes` 缩放（必然在交界帧发生 `1.04 → 1.01` 倒退抽搐）；必须保持单条连续 `<video>` 承载贯穿推镜，或显式衔接首尾 `scale` 值。
4. **声画转场必须成对**：禁止“空放 `whoosh` 音效 + 画面 1 帧干硬切”；任何动势转场声必须匹配 `0.25–0.50s` 视觉过渡（叠化、沉黑、遮罩擦除、空间归位或动感模糊甩切）。当相邻镜头亮度跳变 `|ΔYAVG| > 60`（如暖白纸底切暗色全屏实拍）或人脸倍率跳变 `> 2.0×` 时，**严禁零帧硬切**，必须配置 `0.30–0.45s` 视觉桥接。

## 二、特效质量四条红线（终结“网页 PPT 感”与“伪特效”）

1. **零幽灵剧透（No Ghost Spoilers）**
   - 凡尚未讲到的卡片、清单项、结论条、删除线或金句，触发前**必须设为 `opacity: 0`**（或极轻虚线空槽占位），**严禁使用 `opacity: 0.15–0.55` 半透明灰块提前挂屏剧透**。
   - **焦点退隐（Spotlight & Dimming）**：新观点或正解登场时，被否定的旧方案或已讲完的前序条目应主动**降透明度至 `0.40–0.55` + 降饱和度 `saturate(0.35–0.6)`**，让出视觉重心（严禁划错旧卡后反而变亮抢戏）。
2. **名实相符（WYSIWYG VFX）**
   - 分镜脚本或音效中出现下列关键词时，场景代码必须实装对应真实算法，严禁挂羊头卖狗肉：
     - **「故障 / 倒带」**：实装 3–5 帧确定性 RGB 切片错位（`clip-path: inset` + `mix-blend-mode: screen`）与短闪白/倒滚时间码，且音效峰点误差 `≤ ±50ms`；
     - **「3D 矩阵 / 空间升维」**：实装真透视投影 `k = fov / (fov + rz)`、`z` 深度差 `≥ ±120`、节点按 `rz` Painter's Z-Sort 排序并按 `k` 缩放字号/尺寸；升维前先 `0.25s` 清场收起旧 2D 标签，**严禁多卡叠字撞车**；
     - **「划除 / 否定 / 勾选」**：禁止静态 CSS `text-decoration: line-through` 或超出文字宽度的硬直条 `div`，必须使用贴合字宽的 **SVG `<path>` + `stroke-dashoffset` 笔触描边** 配合微震/回弹；
     - **「锁靶 / 数据流 / AI 对话」**：必须实装 Canvas/SVG 动态准星收缩、沿路径流动发光点（`getPointAtLength`）或确定性流式打字机（`Math.floor(p * text.length)` + 闪烁光标）。
3. **风格纯度红线**
   - **电影感/金句沉浸风（如 `03-v3`）**：**严禁使用静止 `REC` 红点、四角监视器取景框、`SPEAKER CAM · 4K` 等数码录播套壳**；必须以动态宽银幕遮幅、OpenFilm 原生 `--of-lut` / `--of-cutout: 1` 浅景深分离、24fps 确定性胶片颗粒与**真溶黑收尾（终帧黑幕 `opacity: 1.0`）**建立高级光学质感。
   - **科技霓虹风（如 `01-v1`）**：避免满屏套用「`border-radius: 16px` 厚蓝黑盒 + 均匀 `box-shadow`」初代模板；优先工业切角 `clip-path: polygon(...)`、细刻度 HUD、与实拍视频轻冷调统一。
   - **实拍与文字防穿帮**：激光/遮罩擦除两张 B-roll 时，**标题栏必须抽离出被裁切的图像层**防止标题被拦腰切字；CC0 免版权通用 B-roll 登记在 `credits.json` 即可，勿在画面角落贴大块灰色 `Wikimedia CC...` 贴纸破坏质感。
4. **告别单一 `cubic-out` + 0 帧 `className` 跳变**
   - 禁止全片所有元素复制同一段 `1 - (1-x)^3` 位移，也禁止进度条、卡片高亮、打勾盒用 1 帧 `className` 硬跳变；按语义选用下方标准物理缓动与连续插值。
5. **单支视频内视觉素材严格单次使用（Single-Use Visual Asset，`count = 1`，硬性拦截）**
   - 在**同一支成片**内，每一张 B-roll 图、AI 生图、动态贴纸、用户配套预置原图或实拍视频 B-roll 片段（品牌固定 Logo 除外）**严格仅允许使用 1 次**；严禁跨镜重复使用同一张图/视频，也严禁在同一场景里放第二个模糊背景 `<img>` 复用该图。
6. **三层“真会动”配套素材协同**
   - ① **实拍动态视频 B-roll（`.mp4`）**：优先通过 `fetch_asset.py stock --kind video`（或已配免费 Key 的 `openfilm get video-search --orientation portrait`）补充 **1–2 段无水印、3–6 秒真实运动视频**（统一暗角与风格色调，严禁硬塞无关画面）；
   - ② **OpenFilm 离线动态贴纸（`openfilm get sticker`）**：主动调用本地离线自带的 1,587 个免费动态贴纸（会动的箭头、强调圈、勾选、警示、信号等），按风格克制点缀关键金句与引导点（单支片内每枚同样限 1 次，电影槽位 `03-v3` 克制或不用）；
   - ③ **静态图动效合成化**：所有静态 `.jpg` / 预置手册图入画须叠加语义 SVG/Canvas 前景动效（扫光、数据流光点、准星聚焦、局部高亮框），避免纯静图干推。
7. **前景 / 人后特效层级与人物零遮挡硬规（严禁大头吞字与贴纸糊脸）**
   - **① 信息型特效/文字/SVG 图表严禁放人物背后**：凡需要观众读清的文字、数据图、流程图、警示圆环或对比卡片，**严禁**塞进 `--of-cutout: 1` 人物背后被头肩遮挡；必须改走以下三路之一：**全屏切出 SVG/Canvas 动态舞台**、**顶部 PiP 口播 + 下半屏独立动画区（物理分家）**，或在全屏口播上以**前景上层（`overlays`）避让叠加**（仅落于眉顶留白 `y=190..310px` 或人物上提后的胸腹暗化区 `y=1150..1520px`，绝不压脸/嘴）。
   - **② `--of-cutout: 1` 人后层三重准入铁律（缺一不可）**：
     - **构图必须缩小下沉**：人物抠像绝不能沿用大头特写（如 `height: 1840px; top: -60px`），必须缩小为中景胸像并下沉，使**头顶稳落 `y ≥ 640px`**，完整腾出上半屏 **`y = 210..620px`**；
     - **人后仅限“纯氛围装饰”或“2–4 字超短单行巨字”**：纯氛围层（浅景深背景虚化、环境辉光、微弱粒子）不受遮挡影响；人后巨字仅限 **2–4 字单行短词**摆在头顶上方 `y = 260..540px`，**最多允许发梢轻压底部笔画 ≤ 10%–15%** 制造纵深感，保证 100% 一眼认全；**超过 4 字的长句或精细 SVG 图解一律禁放人后**，改放前景下方安全区或全屏切出；
     - **近景机位不适配即禁用**：若源片本身为近景大头（下沉会截肩穿帮），直接禁用人后大字，改为「背景虚化浅景深 + 前景动效」或「全屏 / PiP 分屏动画」。
   - **③ 动态贴纸（`stickers`）头肩避让与语义锚定**：贴纸严禁浮空乱拍坐标；必须锚定在具体视觉载体旁（顶标胶囊外侧、底卡角标、全屏动画节点旁），有全屏或抠像人物出镜时**严禁落入人物头肩中心禁区（约 `x = 220..860, y = 280..1020`）**与右侧平台按钮禁区（`x ≥ 920`）。
8. **`speaker-pip` 画中画与全屏口播五官完整防截断硬规（严禁扁窗切嘴/切下巴与漏杂墙）**
   - **① 开工前先测源片人脸归一化基准 `speaker_framing`**：对 16:9 横屏或 9:16 竖屏口播源片抽 1 帧叠 10% 网格，实测头顶 `head_top_v`（常约 `0.18–0.22`）、眉眼 `eyes_v`（`0.42–0.48`）、嘴唇 `mouth_v`（`0.56–0.62`）、下巴 `chin_v`（`0.65–0.70`）、领口麦 `collar_v`（`0.73–0.78`）及干净背景右界 `clean_bg_right_u`（如右侧有灰色吸音墙则 `u ≈ 0.57`），记入 `storyboard.json`。
   - **② `speaker-pip` 纵向五官完整保留公式（硬性阻断红线）**：
     - 设 `<video>` 盒尺寸为 `W × H`，稳态 `clip-path: inset(T R B L)` 裁切后在源片（计入 `object-fit: cover` 溢出）上的纵向保留区间为 `[v1, v2]`：
     - **上边界 `v1 ≤ head_top_v - 0.04`（通用上限 `v1 ≤ 0.22`，推荐 `≤ 0.16`）**，严禁削掉头顶头发；
     - **下边界 `v2 ≥ chin_v + 0.06`（通用硬下限 `v2 ≥ 0.72`，推荐 `≥ 0.75` 直至领口/麦夹，即 `inset_bottom / H ≤ 0.26`！）**。**严禁出现 `inset_bottom / H > 0.28`（如 `335px / 799px = 41.9%` → `v2 = 0.581`）一刀切在鼻孔下方把说话人的嘴巴与下巴全部截断的重大穿帮！**
     - **可见窗口净高 `H_vis = H - T - B ≥ 340px`（推荐 `380–430px`）**；若分镜页面绘制了装饰外框 `.pip-frame`，其四边必须与 `clip-path` 稳态可见像素框 `[left+L, top+T, W-L-R, H-T-B]` 严格对齐（误差 `≤ 6px`），严禁外框二次遮脸。
   - **③ 去背景死墙的正确几何做法（严禁靠放大人物硬塞扁宽窗）**：
     - 在 `2.2:1` 扁宽框里放大人物去填满宽度，几何上必然把嘴巴和下巴挤出下边界！
     - 若源片一侧有杂乱背景墙（如 `u > 0.575` 灰墙），必须采用以下二选一：**A. 居中紧凑 `4:3` / `16:10` 圆角人像窗**（如 `<video>` 设 `width: 960px; height: 540px; left: 100px; top: 140px`，配合 `clip-path: inset(54px 410px 110px 60px round 20px)` → 可见框 `490 × 376px`、`u2 = 0.573` 彻底切净右侧灰墙，且 `v1 = 0.10, v2 = 0.796` 完整保留头顶至领麦！）；或 **B. 左半人像窗 + 右半实时口播关键词看板**。
9. **音画字逐句同步四条铁律（彻底终结“t=0 摊牌剧透、前半抢跑后半死镜、跨镜借词、脑补文字打架”）**
   - **① 强制锁死 `local_t = cue_start - clip_at`（严禁拍脑袋填 `0.2 + i * 0.8` 等差秒数）**：
     - 编写任何 `scenes/*.html` 前，**必须先生成并校对好 `scenes/subtitles.html` 的精确 `CUES` 时间戳**；
     - 在每个分镜的 `<script>` 顶部，必须显式用常量写出本镜内每句口播的真实局部触发秒数并附台词注释，例如：
       ```js
       // clip at=34.60s; CUES: [34.69, '现在跨境电商圈子普遍看'], [38.53, '没有很多新品牌冲入赛道']
       const T_SCOPE = 0.09; // 34.69 - 34.60
       const T_BRAND = 3.93; // 38.53 - 34.60 说到“新品牌”瞬间触发闸门拦截与主结论！
       ```
   - **② 第 0 帧零摊牌与渐进揭示（Progressive Reveal）**：
     - 镜头切入瞬间（`t = 0..0.40s`），画面最多只允许出现 **1 个顶标胶囊（`≤10` 字）+ 空容器骨架 + 第 1 句正在说的关键词**；
     - 凡对应本镜第 2 句及后续分句的标题、SVG 节点框、数据条、底部总结栏，**在 HTML/SVG 初始状态必须设为 `opacity="0"`（或 `style="opacity:0"`）**，严格等到 `t >= local_t - 0.05` 说话人开口读到该词瞬间才弹出/描边点亮！严禁第 0 帧把全镜 5–9 个文字节点一次性亮在屏幕上提前剧透 3–12 秒。
   - **③ 动画全生命周期覆盖与长覆盖层拆分（严禁前 40% 演完、后 60% 死镜）**：
     - 时长 `≥ 4.8s` 且含 2 句以上台词的分镜，其最后一个离散视觉动作触发点 `max(local_t)` **必须对齐本镜最后一句核心台词的 `local_t`**，严禁前 `1.5–2.1s` 把所有线条/柱子一次性画完，让后半程 4–5 秒说话时画面完全静止；

## 三、OpenFilm 0.1 可复用 `motion-kit` 原语库（直接套用）

### 1. 四类标准缓动函数（写入 `frame(t)`，严禁依赖 CSS `transition`）

```js
const clamp = (v, a = 0, b = 1) => (v < a ? a : v > b ? b : v);
// 1. 电影急停（卡片/文字高速滑入、丝滑收刹）
const easeOutExpo = (x) => { const c = clamp(x); return c === 1 ? 1 : 1 - Math.pow(2, -10 * c); };
// 2. 弹性过冲（勾选盖章、结论爆点、徽章弹出）
const easeOutBack = (x) => { const c = clamp(x) - 1; return 1 + 2.70158 * c * c * c + 1.70158 * c * c; };
// 3. 物理阻尼弹簧（强节奏弹窗、撞击落位）
const spring = (x) => { const c = clamp(x); return c === 0 ? 0 : c === 1 ? 1 : 1 - Math.exp(-8 * c) * Math.cos(10 * c); };
// 4. 柔和呼吸（电影推镜、暗角/光斑流转）
const easeInOutSine = (x) => -(Math.cos(Math.PI * clamp(x)) - 1) / 2;
```
