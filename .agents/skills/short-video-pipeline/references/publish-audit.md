# 发布前审核（Pre-Publish Audit）强制门禁

本文件与 [creatorhub-api.md](creatorhub-api.md) 解耦，专注发布前的媒体规格、文本洁净度、合规风控与各平台表单硬性校验，不依赖 CreatorHub 源码结构。

**强制门禁原则：无论是调用 CreatorHub 发布建任务接口（`POST /api/publish`），还是带定制封面交付用户手动发布，都必须先按本文件对每个目标平台逐项完成发布前审核。未通过硬性项的平台一律不得建任务或放行交付，防止表单报错、内容截断、视觉瑕疵或产生 `uncertain` 脏任务。**

## 一、通用发布前审核项（全平台必查，均为硬性拦截）

| 检查项 | 级别 | 校验标准 |
|---|---|---|

| **2. 文本洁净度** | 硬性拦截 | 标题、正文、话题中不得残留占位符（如 `TODO`、`xxx`、`<标题>`、`{{...}}`）、Markdown 语法符号（`**`、`##`、`[]()`、`__`、反引号）、不可见控制字符（零宽空格、异常 `\r`/`\t` 等）、多余首尾空白或明显错别字。 |
| **3. 话题格式与拼接总长** | 硬性拦截 | 传给 API 的 `topics` 统一以英文逗号 `,` 分隔，每项不带 `#` 前缀、不含空格与非法符号、无重复标签；供人工复制的 `topics_display` 统一为 `#词1 #词2` 空格分隔单行；同时按实际发布形态核算「正文 + 拼接后的 `#话题`（含 `#` 与分隔空格）」总字符数，避免被平台或 CreatorHub 静默截断而腰斩末尾话题。 |
| **4. 平台政策合规风控（1000Hz 哔声 + 某X 脱敏 + 画面去台标）** | 硬性拦截 | **人声、字幕、花字、封面与文案五处同步严查 5 类平台风控词**：① 国内跨平台竞争名（`抖音 / 小红书 / 视频号 / 微信 / 公众号 / 快手 / 淘宝 / 拼多多 / 京东` 等，口播原声必须已用 `1000Hz`「哔」声屏蔽，全部文字同步替换为 `某音 / 某红书 / 某频号 / 某信 / 某手 / 某宝 / 某多多` 等；正常业务词如亚马逊/独立站/领星/AI 保留）；② 站外私域导流词（微信号、手机号、二维码、私信领资料、评论扣1）；③ 广告法极限与保本暴利承诺词（`行业第一 / 全网第一 / 最顶级 / 躺赚 / 稳赚不赔 / 一夜暴富 / 100%有效`）；④ 逃税/刷单/灰色清关/假货等违规词；⑤ 诈骗/传销/杀猪盘/死路/破产跑路等高危风控词。画面中若含第三方平台水印或二维码须已打码/裁除。 |
| **5. 账号与状态预检** | 按需硬性拦截（仅显式启用 CreatorHub 自动发布时必查） | 当前默认停用 CreatorHub 走手动发布交付时跳过此项（在 `audit` 中标 `skipped_manual_delivery` 即可）。若用户显式指令启用 CreatorHub 自动发布，须通过 `GET /api/accounts` 与 `GET /api/publish` / `GET /api/task-queue` 确认目标平台账号为 `active`、账号角色 **`account_role != "crawler"`**（须为 `publish` 或 `hybrid`，否则 CreatorHub `v0.6.0` 会直接返回 400 物理拦截）、未处于写暂停或风控冷却期，且该平台无未核对的 `uncertain` 任务阻断。 |
| **6. 诚实钩子契约、禁歧义生造词、去秒数与账号品牌一致性** | 硬性拦截 | 核对已按 [copywriting.md](copywriting.md) 标明 `content_archetype`（入口 E 同步标明 `account_group` 与 `account_ip_name`）并产出三平台四项文案：**`diagnostic_resonance` 诊断共鸣片严禁在标题、描述、封面伪造「如何破局/怎么破局/决策清单/自查清单/避坑指南/解决方案」虚假承诺**；严禁生造双关歧义缩略词（如「外遇行业内卷」）、论文目录腔短标题及跨槽账号 IP 名串用；**严禁在视频描述（`desc`）中提及任何具体秒数、时间点或片长数字**；属于辰奕系列账号且用户未显式豁免时，核对 `desc` 中完整出现一次原句 **「用AI重构经营，让企业持续增长」** 且标签合理融入品牌词。 |
| **7. 三平台竖版封面精确尺寸、人物头顶居中标题、精确账号 IP 名与 3D FaceMesh 正脸自然神态门禁（生成定制封面时必查）** | 硬性拦截 | **① 三平台竖版精确尺寸与头顶居中硬校验**：核对目标平台 PNG 存在、非空且严格匹配竖版像素标准——**抖音 `1080 × 1920 px`、小红书 `1242 × 1660 px`、视频号 `1080 × 1440 px`**！**封面字幕（两行主标题）必须置于人物头顶上方、水平居中（`text-align: center`）**，严禁标题沉在画面下半部或压额头眉眼；**② 离线 478 点 3D FaceMesh 正对镜头自然神态硬校验**：已运行 `qc_video.py select-cover-frames` 生成 `face-zoom-sheet.jpg` 与 `cover-frame-pool.json`，且渲染落盘的封面 PNG 通过 `audit-render` / `audit-matrix` 内置 CV 人像门禁（正对镜头 `cheek_sym` 达标、`\|roll\| ≤ 9.0°`、双瞳正视镜头 `\|gaze_x - 0.525\| ≤ 0.072`、`min_ear ≥ 0.180`、口唇自然舒适带 `0.44 ≤ lip_fullness ≤ 0.70` & `mar ≤ 0.155`，零侧脸/歪脖/斜视/半闭眼/吞咽抿嘴/露下齿抽象帧），并亲自打开 `output/check/safezone-cover-faces.png`（矩阵另查 `master/output/check/matrix-cover-faces.png`）目视确认；**③ 商业杂志拓扑 `C1–C5` 与精确账号 IP 名硬校验**：**顶部居中刊头微标（`28–36px`）必须印本槽绑定的精确账号 IP 名**（`00=跨境AI十亿增长局`、`01=时奕聊AI经营`、`02=辰奕AI经营实战`、`03=老郑AI经营实战`、`04=老郑AI经营论`），主标题字号抖音 `≥ 104px` / 小红书 `≥ 114px`（机器底线 `110px`）/ 视频号 `≥ 100px`，零小胶囊标签堆砌，亮底（`RGB>185`）零裸抠像贴图。 |

## 二、分平台校验规则（补齐 CreatorHub 未前置拦截的表单坑）

每项规则均标明 **硬性拦截**（不通过必修正或阻断，禁止建任务）或 **建议项**（尽量满足，不单独阻断）。

### 1. 微信视频号（`shipinhao`）

| 检查项 | 级别 | 规则说明 |
|---|---|---|
| **短标题来源与长度** | **硬性拦截** | `title` 必须对应 [copywriting.md](copywriting.md) 的**短标题**（不要把两行封面标题直接塞进短标题框），严格控制在 **6–16 个汉字/字符**（不足 6 字或超过 16 字均可能被平台拒绝或截断报错）。 |
| **短标题符号白名单（含去空格）** | **硬性拦截** | **严禁包含**：逗号（`,`/`，`）、句号（`.`/`。`）、感叹号（`!`/`！`）、顿号（`、`）、破折号（`—`/`-`）、各类括号（`()`/`（）`/`[]`/`【】`）、斜杠（`/`/`\`）、竖线（`|`）、**空格（含中英文间空格）**、换行符及 Emoji 等特殊符号。平台仅允许极少数标点（`《》`、`""`、`:`、`+`、`?`、`%`、`℃`），**默认优先使用纯中文/字母/数字表达**（如将 `AI 对跨境电商的两层影响` 清理为 `AI对跨境电商的两层影响`），尽量避免一切非白名单符号。 |
| **正文 + 话题总长** | **硬性拦截** | 正文与拼接后的 `#话题` 合计 **≤ 1000 字**，不留截断残句。 |
| **位置 `location`** | 建议项（可选） | 不超过 **60 字**；视频号 POI 下拉匹配为实验性能力，匹配失败可能自动跳过，不作为发布成败依赖。 |

### 2. 小红书（`xhs`）

| 检查项 | 级别 | 规则说明 |
|---|---|---|
| **账号创作者权限** | **硬性拦截** | 走 CreatorHub 自动发布时，目标账号必须具备创作者登录（`has_creator=true`），否则接口或发布页必拒。 |
| **标题来源与规范** | **硬性拦截**（上限）/ **建议项**（保守长度） | 按 [copywriting.md](copywriting.md) 映射：`title` 优先采用**单行化封面标题（≤ 18 字且无冲突符号时）**，超限或含冲突符号时回退**短标题**。**硬性**：≤ **20 字**，不得包含 `#`、换行符及站外导流词；**建议**：因 Emoji/特殊符号在前端可能按双字节或加权计数，保守控制在 **≤ 18 字**。 |
| **正文 + 话题总长** | **硬性拦截** | 正文与拼接后的 `#话题` 合计 **≤ 1000 字**，正文必须为话题预留足够字符空间，严禁末尾话题被截断。 |
| **媒体规格** | **硬性拦截** | 视频发布仅限 **1 个文件**且文件大小 **≤ 1 GiB**。 |
| **话题数量** | 建议项 | 控制在 **3–8 个**高相关标签（含品牌词时一并计入），单标签简短无标点。 |

### 3. 抖音（`douyin`）

| 检查项 | 级别 | 规则说明 |
|---|---|---|
| **标题来源与规范** | **硬性拦截** | 按 [copywriting.md](copywriting.md) 映射：`title` 优先采用**单行化封面标题（≤ 30 字）**，超限时回退**短标题**。**硬性**：**≤ 30 字**，不得含换行符、控制字符或堆砌无意义特殊符号。 |
| **正文 + 话题总长** | **硬性拦截**（上限）/ **建议项**（精简长度） | **硬性**：正文与拼接后的 `#话题` 合计 **≤ 2000 字**；**建议**：短视频正文精简在 **300–500 字**内。 |
| **话题数量与格式** | **硬性拦截**（上限与格式）/ **强建议**（下限） | **硬性**：≤ **5 个**（超过 5 个易被平台截断或触发校验失败），API 侧无 `#` 前缀与空格；**强建议**：控制在 **3–5 个**（含辰奕品牌词时可取 `#辰奕` 与 `#用AI重构经营`，把余位留给行业与核心主题词）。 |
| **可见性与保存权限** | **硬性拦截（显式确认）** | 自动发布建任务前显式确认 `visibility`（默认 `public`）与 `allow_save`（默认 `true`）符合用户意图。 |

## 三、审核执行机制（放行、自动修正与阻断）

### 1. 逐平台输出审核清单并落盘
调用 `POST /api/publish` 或交付手动发布前，必须对每个目标平台逐项检查，并将结果写入 `runs/<目录>/publish/publish.json` 的 `audit` 字段：

```json
{
  "audit": {
    "checked_at": "2026-11-23T21:20:00+08:00",
    "passed": true,
    "common": {
      "media": { "passed": true, "codec": "h264+aac", "duration_sec": 28.5, "size_bytes": 12345678 },
      "copywriting": { "passed": true, "brand_slogan_checked": true, "note": "" },
      "covers": { "enabled": true, "passed": true, "spec_path": "runs/<目录>/covers/cover-spec.json" },
      "compliance": { "passed": true, "note": "" }
    },
    "platforms": {
      "shipinhao": {
        "passed": true,
        "checks": [
          { "item": "短标题长度(6-16)与符号/无空格白名单", "level": "hard", "passed": true },
          { "item": "正文+话题总长(<=1000)与四项文案齐全", "level": "hard", "passed": true },
          { "item": "封面尺寸(1080x1440)与人物头顶居中视觉自检", "level": "hard", "passed": true },
          { "item": "账号状态/角色(!=crawler)/无uncertain阻断", "level": "hard", "passed": true }
        ],
        "auto_fixes": [
          {
            "field": "title",
            "reason": "视频号短标题含中英文空格",
            "before": "AI 对跨境电商的两层影响",
            "after": "AI对跨境电商的两层影响"
          }
        ],
        "blocked_reasons": []
      }
    }
  }
}
```

### 2. 可自动修正的格式问题（修正后必须复审）
属于纯格式/长度/符号问题，且能在**不改变原意**的前提下无损修正时，由 Agent 自动重写修正：
- 视频号短标题含中英文空格或禁用符号（如逗号、感叹号、Emoji）、超过 16 字或不足 6 字；
- 小红书封面标题超过 18/20 字需回退短标题、抖音标题超 30 字或含换行；
- API 侧 `topics` 带 `#` 前缀、含空格/中文逗号分隔、有重复项或抖音话题超过 5 个；
- 正文残留 Markdown 符号、多余首尾空白，或「正文 + 话题」总长超限；
- 视频描述（`desc`）误含具体秒数、时间点或片长表述（如「第24秒起」「最后30秒」「这条48秒短片」「1分35秒」），无损改写为自然内容节点指代（如「后半段」「片尾」「这条短片」）。

**修正后必须重新跑一遍完整审核**，确认所有硬性项全部通过后才允许调用 `POST /api/publish` 或放行交付，并在 `publish.json` 的 `audit.platforms.<平台>.auto_fixes` 中保留修正前后的 `before` / `after` 差异。

### 3. 不可自动修正的阻断项（禁止带病强行提交或交付）
出现以下任一情况，**必须立即阻断该平台发布/交付**，不得调用 `POST /api/publish`：
- 视频文件损坏、缺视频流或音轨、编码异常、体积超目标平台限额；
- 走自动发布时，账号登录失效、账号角色为仅采集号（`account_role=crawler`）、无创作者权限（小红书 `has_creator=false`）、处于写暂停/风控冷却，或该平台存在未人工核对的 `uncertain` 任务；
- 本次任务要求做定制封面但封面缺失、像素尺寸不符、标题行宽超限或视觉检查未通过；
- 内容触及明显违禁词、站外硬导流、极限绝对化承诺或未证实数据等合规红线，或封面承诺与成片严重脱节；
- 用户明确指定了固定文案，但与平台硬限制冲突且无法无损改写。

阻断时向用户清晰报告**具体失败项与修改建议**；若本次同时发多个平台，其余已通过审核的平台可按既定流程继续执行（如用户要求“一票否决/全停”则整单停下）。

## 四、实测踩坑补充（动态沉淀区）
