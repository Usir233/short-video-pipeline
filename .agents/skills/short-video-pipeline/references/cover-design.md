# 短视频三平台竖版商业画报封面设计规范（全工作区通用标准）

本工作区**所有视频统一只制作竖版（`1080 × 1920`，不制作横版视频）**，所有定制封面一律执行本**唯一通用商业人像画报规范**（不设任何特定专题/单期定向模板）：
- **三平台竖版封面精确尺寸固定为**：抖音 **`1080 × 1920 px`**、小红书 **`1242 × 1660 px`**、视频号 **`1080 × 1440 px`**；
- **封面字幕（两行主标题）统一放置在人物头顶上方、水平居中（`text-align: center`）**；
- **顶部居中刊头微标强制印对应账号精确 IP 名**（入口 E `00–04` 严格一一绑定 `G0–G4` 五大账号组 IP 名，严禁漏印、自编泛栏目名或跨槽串台）。

## 二、版式与排印硬规则（头顶水平居中标题 + 精确账号 IP 名 + 巨字视觉锤）

所有封面 HTML/渲染脚本必须逐条满足以下硬指标（由 `qc_video.py` 自动扫描源码并由主 Agent 看图复核）：

1. **封面字幕（两行主标题）强制置于人物头顶上方、水平居中**：
   - 统一采用**「上：居中精确账号 IP 微标 + 人物头顶上方水平居中两行大标题（`width: 100%; left: 0; text-align: center`） → 中下：有神半身人像主体」**的黄金头顶居中构图；
   - **严禁将主标题沉在画面中下半部**（禁用 `bottom:` 定位、`justify-content: flex-end`、过大 `top / margin-top / padding-top` 或 `translateY` 下推），也**严禁让标题下缘压住人物额头或眉眼**（标题底边与发顶之间预留 `20–48px` 干净呼吸间距）；
   - 字体统一使用 **Noto Sans SC（思源黑体 700/900）** 或 **Noto Serif SC（思源宋体 700/900）**，两行主标题优先直接承接 [copywriting.md](copywriting.md) 产出的 `cover_title`（第一行短句抓痛点/反差，第二行点价值/悬念，严禁折第 3 行）。
2. **顶部居中精确账号 IP 名微标（严禁混乱串名或自造栏目名）**：
   - 在头顶主标题正上方的居中刊头位（字号 `28–36px`）必须印**本片绑定的精确账号 IP 名**（严禁把任何手机号写入文件！）：
     - `00-master` ↔ **`G0` · `跨境AI十亿增长局`**
     - `01-v1` ↔ **`G1` · `时奕聊AI经营`**
     - `02-v2` ↔ **`G2` · `辰奕AI经营实战`**
     - `03-v3` ↔ **`G3` · `老郑AI经营实战`**
     - `04-v4` ↔ **`G4` · `老郑AI经营论`**
   - 单片流程（入口 A/B/C/D）若用户指定了目标账号组则印该账号精确 IP 名，未指定时默认印主号 IP 名（如 `老郑AI经营实战`）；
   - **严禁自编泛化栏目名（如“商业观察”“深度专栏”），严禁把 A 号组的 IP 名误印到 B 号组封面上，且封面所有可见文字严禁出现未脱敏平台敏感词或生造双关歧义词**。
3. **三平台头顶居中坐标、主标题字号下限与行宽公式**：
   - **抖音（`1080 × 1920`）**：居中账号 IP 微标 `y = 250..296px` → **人物头顶水平居中两行主标题 `y = 312..576px`**（主标题 `font-size` **`≥ 104px`**，推荐 `108–122px`；`字号 × 字数 ≤ 980px`）→ 人物头顶 **`head_top_y ≥ 606px`**；
   - **小红书（`1242 × 1660`）**：居中账号 IP 微标 `y = 84..134px` → **人物头顶水平居中两行主标题 `y = 152..442px`**（主标题 `font-size` **`≥ 114px`**，机器底线 `110px`，推荐 `118–136px`；`字号 × 字数 ≤ 1120px`）→ 人物头顶 **`head_top_y ≥ 472px`**；
   - **视频号（`1080 × 1440`）**：居中账号 IP 微标 `y = 68..112px` → **人物头顶水平居中两行主标题 `y = 128..392px`**（主标题 `font-size` **`≥ 100px`**，推荐 `104–116px`；`字号 × 字数 ≤ 980px`）→ 人物头顶 **`head_top_y ≥ 420px`**；
   - *(注：行宽核算时英文大写词如 `"AI"` 按 `1.25` 字计，标点按 `1` 字计；若超宽则微调精炼文案或按档收字号，并同步回写 `publish/publish.json`。)*
4. **砍净琐碎网页卡片框**：
   - 同屏文字严控 `≤ 2` 级（顶部居中精确账号 IP 微标［`C5` 可并列划除旧误区小标］+ 人物头顶水平居中两行主标题）；
   - **严禁在人物周围堆砌 `≥ 3` 个 `≤ 38px` 带边框/底色的小胶囊标签（`.tag` / `.pill` / `.chip`）、严禁画全画布 `1–2px` 细线外框、严禁追加 `< 36px` 小副标、严禁放 Emoji 贴纸**。

## 三、前置网格五维选帧与人像光学精修铁律

1. **前置网格选神态协议（必产 `materials/covers/contact-sheet.jpg`）**：
   - 严禁盲填秒数抽帧！开工先用 `ffmpeg`（优先加 `-hwaccel cuda`）从干净无字幕源片（如 `master-assets/clips/`）按均匀步长抽取编号缩略图（单片 `16–24` 张，**入口 E `20–30` 张**）拼成 `materials/covers/contact-sheet.jpg`；
   - Agent 必须用看图工具亲自审阅接触表，按**五维黄金表情标准**挑出各平台截帧（入口 E 跨 5 片抽帧间隔 `≥ 6.0s` 且 `64-bit dHash` 互异，同片三平台间隔 `≥ 2.5s`，确保全部封面神态零重复）：
     - ① **零遮脸**：手掌、手指、道具严禁遮挡眉眼、鼻梁、嘴唇或推眼镜梁；
     - ② **眼神定格有高光**：双眼睁开度 `≥ 80%`，视线平视或微斜定焦，镜片反光不压瞳孔，**严禁选眼球下垂看桌面的念稿帧**；
     - ③ **嘴型紧致笃定**：选微抿定格或重音清晰张口帧，**严禁选嘴角松垮微张、单露下排牙的过渡废帧**；
     - ④ **零动态拖影与边缘残肢**（严禁画面角落漏出半截被羽化截断的手指，人物下缘须自然隐入底部暗区或画框内，不露生硬裁切边）；
     - ⑤ 在 `cover-spec.json` 必填 `"contact_sheet"` 相对路径、`"account_ip_name"`、`"title_placement": "overhead_centered"` 与每张封面的 `"frame_selection_note"`。
2. **抠像禁区与实景光学精修铁律**：
   - 凡非影棚绿幕拍摄、或人物为蓬松卷发 / 佩戴半透明细框眼镜 / 室内暗光源片，**严禁在亮色背景（背景 RGB 均值 `> 185`）上裸放透明抠像 PNG**（必出灰雾碎发与碎镜框脏边，由 `qc_video.py` 硬拦截）！亮底一律采用实景摄影内画框（`.photo-frame { overflow: hidden }`）裁切；
   - 深暗底封面推荐默认采用**实景原帧光学精修**（上部与底部平滑暗化托字 + 背景轻景深虚化 + 面部曲线提亮去黄绿浊气）；若深暗底确需抠像，使用 `rea-video/.venv`（自动走 GPU `CUDAExecutionProvider`）执行 Alpha 内缩 `2px` + 肩颈自然受光过渡，**严禁在人物背后垫 `border-radius: 50%` 圆形发光 `div` 充当假手电筒背光**。

## 五、归档路径、看图质检与手动发布协同

1. **单片归档路径**：
   - 过程文件（`contact-sheet.jpg`、抽帧原图、HTML 模板）：`runs/<目录>/materials/covers/`；
   - 成品与记录：`runs/<目录>/covers/douyin.png`（`1080×1920`）、`runs/<目录>/covers/xhs.png`（`1242×1660`）、`runs/<目录>/covers/shipinhao.png`（`1080×1440`）、`runs/<目录>/covers/cover-spec.json`。
2. **入口 E（1 母片 + 4 子片矩阵）防传混归档路径**：
   - `00-master`（`G0 跨境AI十亿增长局`）→ `master/covers/00-master-{douyin,xhs,shipinhao}.png`
   - `01-v1`（`G1 时奕聊AI经营`）→ `variants/v1-*/covers/01-v1-{douyin,xhs,shipinhao}.png`
   - `02-v2`（`G2 辰奕AI经营实战`）→ `variants/v2-*/covers/02-v2-{douyin,xhs,shipinhao}.png`
   - `03-v3`（`G3 老郑AI经营实战`）→ `variants/v3-*/covers/03-v3-{douyin,xhs,shipinhao}.png`
   - `04-v4`（`G4 老郑AI经营论`）→ `variants/v4-*/covers/04-v4-{douyin,xhs,shipinhao}.png`
   - 全部通过 `qc_video.py audit-render` / `audit-matrix` 与主 Agent 看图复核后，同步归集至 `runs/<目录>/delivery/00-master/` 与 `delivery/01-v1-*/..04-v4-*/`。
3. **工具链与发布协同**：
   - 全程先执行 `. .agents/skills/short-video-pipeline/scripts/env.sh`，复用工作区 `ffmpeg`、`rea-video/.venv` 与 `browsers/ms-playwright/` 无头截图出图；若当前 Agent 无看图能力，严禁伪造视觉通过，须将 `cover-spec.json` 标为 `"pending_human_visual_review"` 并置 `run.json` 为 `waiting_approval` 交用户目检；
   - 本工作区默认停用 CreatorHub（且 CreatorHub 截至 `v0.6.0` 不支持为国内三平台上传自定义视频封面），过审后统一置 `status: "made"`、`publish_mode: "manual_with_covers"` 交付用户手动连同封面发布。
